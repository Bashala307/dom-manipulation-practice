# JS DOM Practice: Task Manager

Цей проєкт — мій навчальний застосунок для роботи з DOM-деревом, станом даних та `localStorage` у чистому JavaScript.

## 🛠 Технології
Проєкт реалізований без використання зовнішніх фреймворків чи бібліотек, що дозволило детально розібратися у принципах роботи вебу:
* **HTML5/CSS3:** Адаптивна верстка з використанням Flexbox.
* **JavaScript (ES6+):** * Робота з DOM-вузлами (динамічне створення елементів).
    * Обробка подій (Event Bubbling, Listeners).
    * Робота з `localStorage` для збереження стану між сесіями.
    * Маніпуляція масивами даних (метод `filter` для видалення завдань).

## 🚀 Функціонал
* **Динамічний рендеринг:** Список завдань оновлюється автоматично при додаванні або видаленні елементів.
* **Персистентність:** Дані зберігаються у браузері, тому завдання не зникають після оновлення сторінки.
* **Інтерактивність:** Користувач може позначати завдання як виконані та видаляти їх.
* **Модальне вікно:** Зручний UI для додавання нових завдань з вибором пріоритету.

## 🧠 Що я тут практикував?
Це було чудове тренування "бази", яка необхідна для розуміння сучасних фреймворків (React/Vue/Angular):
1. **Синхронізація стану:** Розуміння того, як дані (масив) повинні відображатися в інтерфейсі.
2. **Event Delegation:** Розуміння того, як події спливають у DOM.
3. **UX-підхід:** Очищення полів вводу, валідація, закриття модалок після успішної дії.
